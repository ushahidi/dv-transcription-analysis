# Gemini Flash ASR benchmark

Baseline word-error-rate (WER) evaluation of Gemini Flash on this project's
African-language test sets - a second engine to compare against
[whisper/](../whisper/README.md), scored on the same shared FLEURS clips in
[../data/](../data/README.md) (see [Why a separate folder](#why-a-separate-folder-from-whisper) below).

USH-2516 asked whether Google's Chirp 3 could be added here - it can't, in the
way Whisper is: Chirp 3 is a proprietary Google Cloud model, API-only, no
downloadable weights (see [chirp/README.md](../chirp/README.md) for that
engine, and its caveats). Gemini Flash was picked to go first because it only
needs a free API key, no GCP project or billing account.

## Layout

```
gemini/
├── lib/            # shared code - config loading, dataset I/O, metrics, the Gemini client
├── scripts/
│   └── run_baseline.py      # WER + confidence report for a Gemini model
├── english/
│   ├── config.yaml
│   └── results/     # generated by run_baseline.py (gitignored)
└── kiswahili/        # same structure
```

Audio + manifests aren't downloaded here anymore - see
[../data/README.md](../data/README.md); this folder just reads them.

## Setup

```powershell
python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass   # only if activation is blocked
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r gemini/requirements.txt
```

No torch/transformers here - this folder never loads a local model, so it's a
much lighter install than `whisper/`'s.

## External access requirements

- **Internet** is needed at `pip install` time, dataset-download time, and for
  every transcription call.
- **`GEMINI_API_KEY`** - a free key from
  [aistudio.google.com/apikey](https://aistudio.google.com/apikey). No Google
  Cloud project, no billing account. Set it before running `run_baseline.py`:
  ```powershell
  $env:GEMINI_API_KEY = "..."
  ```
- The free Developer API tier is rate-limited (roughly 5-15 requests/minute).
  `gemini/lib/gemini_client.py` paces calls and retries on 429s, so a 20-clip
  run should complete without manual intervention, just slower than the raw
  API allows.

## Running the pipeline

```powershell
# 1. Pull the eval set, if not already done - see ../data/README.md (shared
#    across every engine folder, not just this one)
python data/scripts/prepare_dataset.py --language kiswahili --split eval

# 2. Baseline accuracy (WER + best-effort confidence)
python gemini/scripts/run_baseline.py --language kiswahili --split eval
```

Results land in `gemini/<language>/results/baseline_<model>_<split>.{json,csv}` -
same shape as `whisper/`'s results files, so the two are directly diffable.
Confidence is best-effort here: Gemini's `generateContent` response only
sometimes exposes `avg_logprobs`; when it doesn't, `confidence` is `null` for
that sample rather than a misleading guess.

## Why a separate folder from whisper/

This folder is structurally independent of `whisper/` - its own
config/metrics/model-calling code, not importing `whisper/lib`. Practical
consequence: `gemini/lib/metrics.py` normalizes text with jiwer's own
lowercase/punctuation/whitespace transforms instead of the
`transformers`-based normalizer `whisper/lib/metrics.py` uses (avoiding a
torch/transformers dependency here) - the two are equivalent in effect, not
byte-for-byte identical, worth knowing if you're diffing WER numbers down to
the third decimal.

The one thing that *is* shared on purpose is the eval data itself - see
[../data/README.md](../data/README.md). That used to be a "not linked to
whisper/" independent download too (each folder pulling its own copy of a
fixed 20-clip test set), until the set grew past 500 clips and duplicating
audio stopped being cheap.

## Choosing a model

`gemini/kiswahili/config.yaml` (via `gemini/lib/default_config.yaml`) defaults
to `gemini-flash-latest` - a Google-maintained alias that always resolves to
the current default Flash model, so it doesn't need bumping every time Google
ships a new one. For a reproducible comparison run, pin an exact model id
instead (e.g. `gemini-2.5-flash`) via `--model` or in `config.yaml` - check the
current alias/model list at
[ai.google.dev/gemini-api/docs/models](https://ai.google.dev/gemini-api/docs/models)
before a real benchmark run, since Gemini model names change over time.

## Adding a new language

Create `gemini/<language>/config.yaml` with `language_name`, `language_code`,
and a `gemini.model`, plus a matching `data/<language>/config.yaml` (see
[../data/README.md](../data/README.md)) if that language isn't already
downloaded - then rerun the two commands above with `--language <language>`.
